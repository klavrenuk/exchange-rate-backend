# Exchange Rate Backend

Бэкенд-сервис для автоматического получения курсов валют НБРБ и сбора графиков IEA с отправкой по email.

Только бэкенд (FastAPI). Фронтенд в другом репозитории.

## Стек
- Python 3.11+, FastAPI, SQLAlchemy 2.0 (async), SQLite (aiosqlite)
- APScheduler для расписания
- httpx + BeautifulSoup для парсинга
- Playwright для скриншотов страниц IEA (опционально)
- openpyxl для Excel-отчётов
- aiosmtplib/smtplib для отправки почты

## Установка
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
# source .venv/bin/activate  # Linux/Mac
pip install -r requirements.txt
playwright install chromium  # для скриншотов IEA
```

## Конфигурация
Скопируйте `.env.example` в `.env` и настройте параметры.
Ключевые параметры:
- `DATABASE_URL` - путь к SQLite
- `MAIL_TO` - список получателей через запятую
- `SMTP_*` - настройки почты
- `MAIL_DRY_RUN=true` - только логировать отправку (без реальной отправки)
- `SCHEDULER_ENABLED` - включить планировщик
- `NBRB_HISTORY_FROM` - дата старта для первоначальной загрузки истории
- `TZ` - таймзона для расписания

## Инициализация БД
При первом запуске приложение автоматически создаст таблицы через `init_db()` в lifespan. Также можно инициализировать вручную:
```bash
python -m app.db.init_db
```

## Запуск
```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
Swagger UI: http://127.0.0.1:8000/docs

## Проверка работы без ожидания следующего дня (ручной запуск)
Через Swagger или curl:

1. Синхронизировать справочник валют НБРБ
```bash
curl -X POST http://127.0.0.1:8000/nbrb/sync-currencies
```

2. Загрузить историю курсов (по умолчанию с `NBRB_HISTORY_FROM` по сегодня). Можно указать валюту и диапазон
```bash
curl -X POST "http://127.0.0.1:8000/nbrb/load-history?cur_abbr=USD&from_date=2020-01-01&to_date=2024-12-31"
```
**Примечание по первоначальной загрузке NBRB:** История загружается через API динамики по каждой валюте батчами по `NBRB_LOAD_BATCH_DAYS`. Для всех валют полный период с 1991 может занять длительное время (много запросов). В текущей реализации загрузка идёт по валютам из справочника с учётом `Cur_DateStart/Cur_DateEnd`. Если весь доступный период не загрузился - это может быть из-за ограничений по времени/запросам. Чтобы продолжить загрузку, просто повторите вызов с нужным `from_date/to_date` или без ограничений по валюте - дубли не создаются (уникальный ключ по валюте+дата).

3. Обновить курсы на сегодня
```bash
curl -X POST http://127.0.0.1:8000/nbrb/update-today
```

4. Сформировать Excel-отчёт за сегодня и отправить по почте
```bash
curl -X POST http://127.0.0.1:8000/nbrb/report-and-send
```
Отчёт сохраняется в `data/reports/`. В шапке Excel указана дата, представлены все валюты с курсами на эту дату.

5. IEA: найти графики на первой странице каталога
```bash
curl -X POST http://127.0.0.1:8000/iea/discover
```

6. Скачать новые графики (HTML, CSV если есть в data-атрибутах, скриншот через Playwright)
```bash
curl -X POST http://127.0.0.1:8000/iea/download-new
```

7. Отправить непросланные графики по одному письму
```bash
curl -X POST http://127.0.0.1:8000/iea/send-new
```

8. Запустить все задачи сразу
```bash
curl -X POST http://127.0.0.1:8000/tasks/run-all
```

## Статус и мониторинг
- `GET /health` - проверка работоспособности
- `GET /status/overview` - сводка по данным и последние запуски задач
- `GET /status/jobs?limit=50` - история запусков задач с деталями и ошибками

## Особенности
- Ошибки одного источника не останавливают остальные - каждая задача обёрнута в try/except, статусы фиксируются в `job_runs`
- Состояние сохраняется в БД - после перезапуска приложение понимает что уже скачано/отправлено
- Уже отправленные графики IEA не пересылаются повторно (таблица `sent_charts`)
- Дубли курсов исключены уникальным индексом (currency_id, date)
- Почта работает в режиме `MAIL_DRY_RUN=true` без реальной отправки
- Все пути и параметры настраиваются через `.env` без изменения кода

## Расписание (автозапуск)
При `SCHEDULER_ENABLED=true` планировщик запускается автоматически:
- NBRB обновление курсов - по `SCHED_NBRB_UPDATE_CRON`
- NBRB отчёт и отправка - по `SCHED_REPORT_CRON`  
- IEA проверка/скачивание/отправка - по `SCHED_IEA_CHECK_CRON`

## Демонстрация
Для демонстрации работы:
1. Настроить `.env` в режиме `MAIL_DRY_RUN=true`
2. Выполнить ручные вызовы 1-7 через Swagger
3. Проверить `data/reports/` - должен появиться Excel-файл
4. Проверить `data/charts/` - должны появиться папки со скачанными графиками
5. Посмотреть `GET /status/overview` и `GET /status/jobs`
